Plain-English definition

Sampling proves possibility; production proves repeatability. The gap between them is where most execution failures start.

Step-by-step lock workflow

Set a golden sample baseline, define tolerance and finish acceptance, run pilot with first-article checks, and route all changes through approval gates tied to document revision control.
