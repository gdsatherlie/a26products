Sampling vs production: why quality drifts after approval.

Teams often celebrate a successful sample and assume production will match it. In reality, production uses different operators, cycle times, and material batches. This guide explains where drift happens and how to prevent it before mass output.

When this matters

If your first run is approaching, this is one of the highest leverage pages to read. Most avoidable warranty and return issues start with weak sample-to-production transfer.

Control steps

  1. Document sample conditions: machine settings, material lot, process sequence.
  2. Define critical-to-quality points with measurable tolerance.
  3. Approve golden sample and retain reference photos and measurements.
  4. Run pilot output before full-scale run.
  5. Compare pilot data to golden sample criteria.

Common mistakes

  • Approving samples without numerical tolerances.
  • Skipping pilot run and moving directly to scale.
  • Changing material source after approval without retest.

Questions for factories

  • What changes between sample and production setup?
  • How do you control first-article approval on the line?
  • What data do you capture during pilot?
